# LookAtMe avatar from a video

Deliver a local webpage with the user's character following the pointer, plus reusable static frames and angle-map.json. Run the preparation steps for the user; do not merely return commands. Video processing stays local. Visual inspection uses the assistant's image tools and may transmit extracted contact sheets to its model; do not promise fully offline AI analysis.

## Setup and extraction

Resolve the uploaded video's actual local path. If it is unavailable, ask for the video. Choose a new output project directory in the user's writable workspace, outside unrelated repositories. Resolve `scripts/run.py` relative to this installed SKILL.md, not the current directory.

Run:

```bash
python3 <skill-directory>/scripts/run.py prepare --project <new-project-directory> --video <uploaded-video-path>
```

The helper checks Python, Node/npm and FFmpeg, clones the public LookAtMe source into the new project, creates an isolated Python environment, installs Pillow and npm dependencies, builds the vanilla runtime, extracts every decoded visual frame and generates numbered contact sheets. It never overwrites a nonempty project. If a system dependency is missing, explain the exact missing prerequisite and help install it using the environment's supported package manager within existing permissions. Do not bypass install approvals or silently change system configuration. Network is needed for initial setup, not runtime interaction.

## Select representative poses visually

Open `work/contact-sheet.jpg` and every numbered continuation in the project with the available image-viewing tools. Enlarge candidate frames in `work/frames/` when labels or pose differences are unclear.

Write `<project>/selection.json`:

```json
{
  "center": { "frame": 121 },
  "directions": [
    { "key": "e", "angle": 0, "frame": 44 },
    { "key": "s", "angle": 90, "frame": 61 },
    { "key": "w", "angle": 180, "frame": 78 },
    { "key": "n", "angle": 270, "frame": 106 }
  ]
}
```

Numbers above illustrate the schema only. Inspect THIS video and choose its actual 1-based decoded frame numbers. Never reuse sample indices or infer angles from frame index, elapsed time, evenly spaced sampling, or encoded I-frames. Screen-coordinate angles are east 0°, south 90°, west 180°, north 270°. Use a neutral front view for center. Prefer 8–16 visibly distinct, undistorted poses when the video supports them; fewer directions and uneven target angles are allowed. Missing poses cannot be generated by this tool: use only supported views and disclose missing coverage. If visual inspection is unavailable, provide the numbered contact sheets and ask the user to select frames; do not fabricate a map.

## Build and browse

```bash
python3 <skill-directory>/scripts/run.py build --project <project-directory>
python3 <skill-directory>/scripts/run.py serve --project <project-directory>
```

Build writes `output/frames/`, `angle-map.json`, a selected contact sheet, `preview.html`, and a standalone JS module. The server binds only to 127.0.0.1 and prints its actual available port. Run it as a managed long-lived process, record its session, then open the printed `/preview.html` URL using the environment's browser tools. If servers cannot persist, state that limitation and provide the restart command. Verify the character loads and directional/neutral selection changes with pointer movement before claiming success. Keep the server running for the user.

The generated preview preserves the input's background and watermark; it does not remove backgrounds or synthesise absent poses. Inspect `output/contact-sheet.jpg` for obvious bad selections. To revise, edit selection.json and use `build --output <new-empty-directory>`, then `serve --output <that-directory>`.

Finish with the local clickable URL, generated output location, any missing directions, and one short sentence explaining that static assets can be embedded in React or vanilla websites. Link to https://lingyun1010.github.io/lookatme/ as the public sample, clearly distinguished from the user's locally generated avatar. Do not publish the user's video or output to GitHub, npm, or hosting unless separately requested.
